# PR News & Games

Android application for PR News India Private Limited.

## Current starter features
- Hindi-first home screen
- Bottom navigation: Home, News, Games, Profile
- Initial news and games placeholders
- Material 3 theme using PR News India-inspired green and gold

## Run locally
1. Install Flutter SDK.
2. Run `flutter pub get`.
3. Run `flutter run`.

## Next development milestones

- Add authentication and user profiles
- Add games and score storage
- Integrate Razorpay through a secure backend (never expose secret keys in the app)
